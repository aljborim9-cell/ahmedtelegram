# 🤖 لوحة تحكم بوت تيليجرام وسيرفر Backend لتطبيق A2 TV

نظام متكامل يربط تطبيق الـ APK ببوت تيليجرام مكتوب بلغة Python عبر REST API خفيف وسريع.

---

## 🌟 المميزات المكتملة:
1. **ربط القنوات والأقسام**:
   - جلب وتحديث الأقسام والقنوات تلقائياً داخل التطبيق مباشرة من البوت والسيرفر.
   - مزامنة حية وفورية.
2. **إدارة روابط API القنوات**:
   - إضافة وحذف وتعديل روابط API أو ملفات M3U.
   - استيراد القنوات بضغطة زر وتغذية التطبيق بها.
3. **تحديث التطبيق APK**:
   - تعيين رابط تحميل APK جديد ورقم الإصدار وملاحظات التحديث.
   - ظهور نافذة تنبيه للمستخدم داخل التطبيق مع زر «تحديث الآن» للتحميل والتثبيت.
4. **وضع الصيانة (Maintenance Mode)**:
   - تفعيل وإيقاف الصيانة بضغطة زر واحدة من البوت.
   - ظهور شاشة صيانة فورية تغلق واجهة التطبيق مع رسالة مخصصة قابلة للتعديل.
5. **إدارة المشرفين (الأدمن)**:
   - إضافة أدمن جديد وحذف الأدمن.
   - تحديد صلاحيات مخصصة لكل أدمن (قنوات فقط، صيانة فقط، تحديثات فقط، أو كامل الصلاحيات).
6. **أمان كامل للمعلومات السرية**:
   - حفظ `BOT_TOKEN` و `ADMIN_ID` داخل ملف `.env` المحمي وعدم إرسالها للتطبيق أو المستخدمين.

---

## 🚀 طريقة التثبيت والتشغيل:

### 1. إعداد المتغيرات في ملف `.env`:
قم بفتح ملف `.env` وضع التوكن والآيدي الخاص بك:
```ini
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRstuVWXyz
ADMIN_ID=123456789
API_HOST=0.0.0.0
API_PORT=8080
```

> **ملاحظة:** 
> - احصل على `BOT_TOKEN` من البوت الرسمي [@BotFather](https://t.me/BotFather).
> - احصل على آيدي حسابك `ADMIN_ID` من البوت [@userinfobot](https://t.me/userinfobot) أو أرسل أمر `/id` لهذا البوت.

### 2. تشغيل السيرفر والبوت:
```bash
python3 run.py
```

سيتم تشغيل سيرفر الـ API على: `http://0.0.0.0:8080` وبوت التيليجرام في نفس الوقت.

---

## 📡 روابط الـ API المتاحة للتطبيق:
- معلومات وحالة التطبيق: `GET /api/app-config`
- قائمة القنوات: `GET /api/channels` (أو `GET /api/channels?category=sports`)
- قائمة الأقسام: `GET /api/categories`
- حالة وضع الصيانة: `GET /api/maintenance`
- فحص توفر تحديث: `GET /api/update?current_version=2`
- روابط البث و M3U: `GET /api/channel-apis`
